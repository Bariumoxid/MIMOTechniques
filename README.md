# CSI-Feedback-Driven Link Adaptation in 5G NR Downlink MIMO

A link-level simulation study of CSI-feedback-driven link adaptation in 5G NR downlink MIMO systems.

This repository contains the MATLAB simulation code, batch execution scripts, test case index, weekly progress records, and final submission materials for the project.

## Requirements

The project was developed and tested using the following software:

- MATLAB R2025a
  - 5G Toolbox
  - Parallel Computing Toolbox
- Origin 2024
- Python 3.13
  - Required Python packages should be installed before running any Python-based scripts or post-processing tools.

## Main Simulation Files

The main batch simulation script is:

```text
Batch_Run.m
```

This script supports running simulations in batches and calls the main simulation function:

```text
FUNCTION_Run_5G_Simulation.m
```

## Weekly Progress Records

Weekly progress documents are stored in:

```text
progress/
```

These files record the development process, intermediate findings, and project updates throughout the study.

## Test Case Index

The full list of simulation test cases is provided in:

```text
5GNR_Full_List.xlsx
```

This spreadsheet includes the simulation groups, parameter settings, and corresponding test case identifiers.

## Final Submission Materials

The final submitted materials are stored in the following folders:

Final_Report/kb784_FinalReport.pdf
