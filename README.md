# 5GMIMO

Matlab simulation files for 5G NR based on 3GPP standards.

Required application and toolboxes:
- MATLAB R2025a
  - 5G Toolbox
  - Parallel Computing Toolbox
- Origin 2024
- Python 3.13 (with all required packages)

Main simulation file:
- Batch_Run.m, supports simulation in batches, calling the FUNCTION_Run_5G_Simulation.m file.
